Get started

  1. Extract the Windows ZIP and open XDesk.exe.
  2. Keep the files together in a fresh folder.
  3. Open Games to add an ISO, XISO, or game folder.

Graphics: Configure resolution, aspect ratio, filtering, upscaling, CRT effects, and downsampling. Settings can be global or per game.

Soundtracks: Use Memory → Manage soundtrack music. The Windows package includes ffmpeg.exe for MP3 conversion.

Updates: Turn startup checks on or off in Settings → Interface. When a new release is available, XDesk offers to install it.

Add your own game images. To fix a wrong automatic cover, open the game's details, choose Search covers, preview artwork, and select Use this cover. Compatible in-game saves can be imported from a legacy XDesk/xemu HDD image.
