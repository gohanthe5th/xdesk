Get started

  1. Extract the Windows ZIP and open XDesk.exe.
  2. Keep the files together in a fresh folder.
  3. Open Games to add an ISO, XISO, or game folder.

Supply your own game images. Install v2.0.2 manually from the full ZIP. Memory can import compatible in-game saves from a legacy xemu HDD. To correct a cover, open the game’s details and choose Search covers.
